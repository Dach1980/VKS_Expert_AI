# Architecture Documentation

This directory contains the accepted architecture baseline for Project Expert AI.

## Baseline

- `ARCHITECTURE_IMPLEMENTATION_GUIDE_v1.0.md` — authoritative architecture snapshot.

Architecture documents describe **what is implemented now**. Future changes belong in `docs/improvements/`; AI quality methodology belongs in `docs/testing/`.

Each important pipeline stage is explicitly classified as CURRENT, LEGACY, EXPERIMENTAL or PLANNED.
