# Step 6 — Golden Case Verification

## Result

Step 6 was executed against the available Experiment 001 evidence and the current normative base. The verification produced **one accepted Golden violation case** and deliberately rejected promotion of unsupported positive cases.

### Accepted Golden case

`EXP001-G001` — `violation`

Subject: direct project reference to `СП 30.13330.2012` for an internal wastewater ventilation decision.

Verification basis:

- project page 10 explicitly cites `СП 30.13330.2012`;
- the current normative base is `СП 30.13330.2020`;
- Rosstandart identifies `СП 30.13330.2012` as replaced and `СП 30.13330.2020` as the replacing document;
- therefore the case can be classified as a violation of normative-reference currency;
- the case does **not** assert that the project value `0.2 м` is itself a violation.

## Cases intentionally not promoted

The existing ventilation candidate with `0.2 м` was not promoted to `compliant` because the available project evidence does not prove the roof condition required to select the `0.2 м` branch of the current rule. The same candidate was not promoted to `violation` because `3.0 м` applies to an exploitable flat roof under the conditions of clause 18.22. A numerical verdict would therefore be an invented assumption.

The existing flow and diameter cases remain `unchecked` because an applicable normative requirement with a verified matching parameter was not established.

The two negative cases remain mandatory `unchecked` controls.

## Golden gate status

The benchmark is **still provisional**. It now contains a verified `violation` case, but it still lacks a verified `compliant` case.

No production Vision, RAG, Checking or Reporting code was changed in Step 6.

## Next action

The next Golden case should be a genuinely verified `compliant` case from the project plus an exact applicable requirement. Until such a case is established, the benchmark must not be upgraded to a complete three-way decision benchmark.
