# VKS Expert AI

Локальный AI-ассистент для проверки проектной документации
разделов водоснабжения и водоотведения по российским нормативам.

## Цель проекта

Автоматизированная проверка:

- пояснительной записки;
- планов;
- схем;
- аксонометрий;
- спецификаций;
- таблиц;
- проектных параметров;

с формированием замечаний и ссылками на нормативные требования.

## Технологии

- Python
- VS Code
- LM Studio
- Qwen3.5-9B
- RAG
- OCR
- Vision
- Rules Engine
- MCP

## Запуск локальной версии

Из корня репозитория:

### Backend

```powershell
python -m uvicorn app.api.main:app --host 127.0.0.1 --port 8000
```

### Frontend

В отдельном терминале:

```powershell
python frontend/start-local-server.py
```
